# Mate Station — sitio web

Sitio estático responsive para presentar el organizador matero Mate Station.

## Probar en tu computadora
1. Descomprimí `mate-station-vercel.zip`.
2. Abrí `index.html` en el navegador. Para probarlo de manera más parecida a producción, usá una extensión de servidor local o ejecutá `npx serve .` dentro de esta carpeta.

## Publicarlo en Vercel
1. Entrá a https://vercel.com/ y creá una cuenta o iniciá sesión.
2. Subí esta carpeta a un repositorio de GitHub.
3. En Vercel, elegí **Add New → Project** y conectá ese repositorio.
4. Como es una web estática, no hace falta framework ni comando de build. Dejá el directorio raíz como `./` y desplegá.
5. Vercel te va a dar un enlace público.

## Antes de vender de verdad
- El formulario de esta versión arma y permite copiar un resumen del pedido; no cobra ni envía automáticamente los datos a un negocio.
- Para recibir pedidos, agregá tu número real de WhatsApp o conectá un formulario/backend.
- Confirmá el precio, materiales, medidas, qué accesorios incluye y las opciones de entrega antes de publicarlos. La web evita inventar esos datos.
- La imagen es una visualización conceptual del producto. La banda de color se superpone para mostrar una vista previa aproximada; no reemplaza un render técnico exacto de cada variante.
